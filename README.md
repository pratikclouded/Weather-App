# Weather-App
A simple yet powerful Weather Application built using Python, Django, HTML, CSS, and external APIs.
This app allows users to search any city and instantly view the live weather report, along with a dynamic background image related to the searched city—fetched automatically using Google Search Engine APIs.

🚀 Features
🔍 Search weather by city name
☀️ Shows real-time weather details including temperature, humidity, wind speed, description, etc.
🖼️ Dynamic city background image appears based on the searched location
⚡ Fast & responsive UI
🌐 Uses Weather API + Google Search API
🎨 Clean frontend built with HTML & CSS
🐍 Backend powered by Django

🧰 Tech Stack
Layer	Technologies
Frontend	HTML, CSS
Backend	Python, Django
APIs Used	Weather API (OpenWeather / other), Google Search Engine API
Others	JSON, Requests Library

🔧 How It Works
User enters a city name.
Django sends the query to the Weather API to fetch real-time weather data.
Simultaneously, the Google Search API fetches an image related to that city.
The page reloads with updated data + the city’s image in the background.
